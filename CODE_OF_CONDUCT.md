# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Our Pledge
We are committed to making participation in this project a harassment-free experience for everyone.

## Our Standards
Examples of behavior that contributes to a positive environment:
- Being respectful and constructive.
- Focusing on technical arguments and evidence.
- Accepting feedback gracefully.

Examples of unacceptable behavior:
- Harassment, trolling, or personal attacks.
- Publishing private information without permission.
- Any behavior that is inappropriate in a professional setting.

## Enforcement Responsibilities
Project maintainers are responsible for clarifying and enforcing standards.

## Scope
This applies within project spaces and in public spaces when representing the project.

## Reporting
Report issues to: security@sovereign.local

## Enforcement
Maintainers may remove, edit, or reject comments, commits, code, issues, and PRs that violate this Code.
