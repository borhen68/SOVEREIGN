# Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - 2026-02-17
### Added
- Company orchestrator (`/api/company/*`) for objective-to-done autonomous execution.
- Security fabric (`/api/security/*`) with pairing, auth, rate limits, sandbox checks, and encrypted secrets.
- Tunnel service (`/api/tunnels/*`).
- Hybrid memory engine (`/api/memory/*`) with chunking, vector+keyword search, and reindex.
- Heartbeat scheduler (`/api/heartbeat/*`) for proactive tasks.
- Setup wizard (`/api/setup/wizard/*`) for quick onboarding scaffolding.
- Observability events and metrics (`/api/observability/*`).
- LLM provider catalog expanded to 22+ openai-compatible providers.
- OSS and deployment files: Apache-2.0 license, governance docs, Docker stack, GitHub workflows.
